# lfd103-a-beginners-guide-to-linux-kernel-development

Course: [A Beginner's Guide to Linux Kernel Development (LFD103)](https://trainingportal.linuxfoundation.org/courses/a-beginners-guide-to-linux-kernel-development-lfd103/)

From: [The Linux Foundation](https://www.linuxfoundation.org/)

Instructor: Shuah Khan

This course gives an introduction to Linux Kernel Development process. 

## Activities
- Lab 5: [Configuring Your Development System](lab5-configure-development-system)
- Lab 6: [Exploring Linux Kernel Sources](lab6-exploring-linux-kernel-sources)
- Lab 7: [Building and Installing First Kernel](lab7-building-and-installing-first-kernel)
- Lab 8: [Writing First Kernel Patch](lab8-writing-first-kernel-patch)
- Lab 9: [Getting Patch Ready and Sending It](lab9-getting-patch-ready-and-sending-it)
- Lab 10: [Kernel and Driver Building, Loading, and Dependencies](lab10-kernel-and-driver-building-loading-and-dependencies)
- Lab 11: [All About Testing](lab11-all-about-testing)
- Lab 12: [Debugging Basics](lab12-debugging-basics)
